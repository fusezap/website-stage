Where it sits

Ordinary software, on top of your stack.

FuseZap isn’t firmware, and it isn’t part of the operating system. It sits on top of the driver and kernel compiler your team already ships.

It works with them, not instead of them.

Models break down into 28 basic operations. Cover these, and every model built from them comes with you. Today that means text models built like Llama, Qwen and Mistral: not yet mixture-of-experts, sliding-window attention or image models. What your chip needs.

01Chapter oneCore & Serve

An engine that writes the kernel for your chip.

When a model asks for a matrix multiply or an attention step, Core writes the kernel for your chip, compiles it with your compiler, keeps it loaded, and launches it.

The few operations that decide speed, like matrix multiply and attention, still get tuned kernels, yours or ours.

What FuseZap does

Serve takes care of everything a customer sees.

Many users at once, the memory each conversation needs, and the OpenAI-compatible API, with streaming, tool calls and structured output.

02Chapter twoPorting

One new backend per chip. Not a port of a framework.

Bringing up a new chip means writing one backend, in four parts. Serve, the models and the API stay exactly the same above it.

If you have a functional simulator, the backend can start before the silicon arrives. That’s how we built Inferentia2’s.

What FuseZap does

A backend in four parts.

A renderer for your kernel language, a hook that calls your compiler, a runtime that launches through your driver, and an allocator for device memory. Each one is yours, handed over with its tests.

04Chapter four · Open sourceApache-2.0

The code is yours,
even if we disappear.

You’re betting years of silicon on the software that runs on it. You shouldn’t have to bet it on us as well.

Core and Serve are Apache-2.0. You can run them, change them and port them to your own chip, and the backend for your chip is yours whatever happens to us. Pilot customers get the source from the day they sign, before the public release.
