Why a matrix

Your chip, on the same table as the names everyone knows.

A customer picks a model first and a chip second. So the question they bring you is always the same: does it run the one we chose?

This table answers it, cell by cell, with a date on every answer. A dash means we haven’t run it. We’d rather show a gap than guess.

One column is still empty: yours.

The full table

Every cell, with its evidence.

Each cell gives a status, the Validate verdict where shown, one number for one request with the baseline on the same kind of machine, and the day we verified it.

  • SupportedPassed a gate on real hardware (Validate PROMOTE, or our package gate), with evidence.
  • PreviewRan on real hardware, but not gated yet, or gated once with a caveat noted in the cell.
  • ExperimentalSimulator only, or behind a flag.
  • PlannedNot run yet. No date is promised.

01Small print, on purposeReading a cell

A number on its own is a brag.

A number with its baseline, its hardware and its date is something you can check.

So every cell carries all of it, and the caveats stay in the cell instead of a footnote nobody reads. Older cells say what has changed since.
