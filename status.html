01In the labInferentia2 · first token

About 5 ms behind.
It bothers us.

Per token, Inferentia2 is now a little faster than AWS’s own library. The first token is not there yet: about 5 milliseconds behind.

We rewrote the kernels that process the prompt, and the first token went from 91 milliseconds to 55, with the same answers, bit for bit. The last few milliseconds are the first thing on the list.

What FuseZap does

What we’re doing about it.
